
# Maison Crumb — Bakery & Pastry Website Template

A modern, responsive bakery and pastry shop website template built with clean HTML, CSS, and JavaScript.

## ✨ Features

* Fully responsive design
* Modern bakery-focused layout
* Semantic HTML5 structure
* Clean and reusable CSS
* CSS custom properties for easy customization
* Dedicated menu page
* Responsive navigation
* Products showcase
* Testimonials section
* Contact & visit section
* Easy to customize
* No frameworks required

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Remix Icon
* Google Fonts

## 📁 Structure

```text
Maison-Crumb/
├── index.html
├── menu.html
├── README.md
├── script.js
├── CSS/
│   ├── style.css
│   └── menu.css
├── Icons/
└── Images/

```

## 🚀 Getting Started

1. Download or copy the template.
2. Open the project folder in your code editor.
3. Customize the content, images, colors and contact details.
4. Open `index.html` in your browser or use Live Server in VS Code.

## 🎨 Customization

Main colors, typography, spacing and other design values can be easily customized through the CSS variables in `style.css`.

Replace the images inside the `Images` folder and edit the content directly in the HTML files.

## 📄 Pages

* `index.html` — Homepage
* `menu.html` — Bakery Menu

## 📝 Notes

* This template uses vanilla HTML, CSS, and JavaScript with no frameworks.
* Replace the included images with your own licensed images when customizing the template.
* When replacing images, using similar image proportions will help maintain the intended layout.
* Keep the existing folder structure and file paths intact to avoid broken links.
* Update the contact details, social links, and other placeholder content before publishing the website.
