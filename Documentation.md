
# Maison Crumb — Documentation

Thank you for purchasing Maison Crumb, a modern bakery and pastry shop website template.

This documentation explains the basic steps for customizing and using the template.

---

## 📁 File Structure

```text
Project Files/
├── index.html
├── menu.html
├── script.js
│
├── CSS/
│   ├── style.css
│   ├── menu.css
│   └── media-queries.css
│
├── Icons/
└── Images/
```

### HTML

* `index.html` — Main homepage
* `menu.html` — Bakery menu page

### CSS

* `style.css` — Main styles for the homepage
* `menu.css` — Styles specific to the menu page
* `media-queries.css` — Responsive styles for smaller screen sizes

### JavaScript

* `script.js` — Interactive functionality such as navigation and FAQ interactions

### Images

The `Images` folder contains the website images, logo, and product photography.

### Icons

The `Icons` folder contains the category icons used throughout the website.

---

## 🚀 Getting Started

No installation or build process is required.

1. Open the project folder in your code editor.
2. Open `index.html` in your browser to view the website.
3. For development, you can use the Live Server extension in Visual Studio Code.
4. Customize the content, images, colors, and contact information as needed.

---

## ✏️ Editing Content

Most website content can be edited directly in the HTML files.

Open:

```text
index.html
```

to edit the homepage content.

Open:

```text
menu.html
```

to edit the bakery menu and product information.

You can customize:

* Bakery name
* Headings and text
* Product names
* Product descriptions
* Prices
* Testimonials
* Address
* Opening hours
* Phone number
* Email address
* Social media links

---

## 🖼️ Replacing Images

Website images are stored inside the:

```text
Images/
```

folder.

To replace an image:

1. Add your new image to the `Images` folder.
2. Open the relevant HTML file.
3. Find the existing image path.
4. Replace the filename with your new image filename.
5. Update the `alt` text to describe the new image.

For the best visual results, use images with similar proportions to the original images.

Keep filenames simple and avoid unnecessary spaces or special characters.

---

## 🎨 Changing Colors

The main design colors are controlled through CSS custom properties in:

```text
CSS/style.css
```

Look for the `:root` section near the beginning of the file.

You can change the color variables to create your own brand color palette without having to search through the entire stylesheet.

---

## 🔤 Changing Fonts

Maison Crumb uses:

* **DM Serif Display** for headings
* **Inter** for body text

The font imports can be found in the HTML files.

You can replace these with other fonts if desired.

---

## 🔗 Editing Links

Navigation links, buttons, social media links, and other links can be edited directly in the HTML files.

When adding your own pages or changing existing page names, make sure the `href` paths match the correct file names.

---

## 📱 Responsive Design

The template is designed to work across desktop, tablet, and mobile screen sizes.

Responsive styles are located in:

```text
CSS/media-queries.css
```

If you make major changes to the layout, check the website at different screen sizes to ensure the content remains readable and properly aligned.

---

## ⚙️ JavaScript

The template uses vanilla JavaScript and does not require any JavaScript framework.

Interactive functionality is handled through:

```text
script.js
```

If you are not familiar with JavaScript, you can leave this file unchanged while customizing the HTML and CSS.

---

## 📝 Important Notes

* Keep the existing folder structure and file paths intact to avoid broken links.
* When replacing images, use appropriately sized and proportioned images.
* Update all placeholder contact information before publishing the website.
* Replace demo social media links with your own links.
* The template does not include a backend, CMS, online ordering system, or payment functionality.
* No build tools or additional installation are required.
